An MCP message writer is registered, but it cannot create household-wide broadcasts. It requires separate message-write consent, allowed recipient resources (people and/or displays), and the delegated member's live rights. An OAuth scope alone does not grant access to arbitrary people, displays, calendar sources, or school sources: grant rows and current server capabilities further constrain each call. The admin policy UI uses separate localized labels for calendar sources the client may read and displays it may access; these selections do not widen the client's OAuth consent.
