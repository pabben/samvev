# Five Samvev design concepts

These diagrams are sanitized structural mockups with fictional content. They are not screenshots of a working application and do not define final colors, typefaces or branding.

Each concept includes an iPhone view, a shared family display and a Shelly Wall Display XL view. Separate light and dark SVGs are included.

| Concept | Primary organizing principle | Best at | Main risk |
|---|---|---|---|
| [1. Nordic Soft Cards](01-nordic-soft-cards.md) | Modules/cards | Flexible mixed overview | Too many modules can create clutter |
| [2. Timeline and Person Columns](02-timeline-person-columns.md) | Time and people | Morning logistics | Untimed messages need a clear home |
| [3. Playful Family Board](03-playful-family-board.md) | Person and routines | Child participation | Must avoid feeling childish to older users |
| [4. Premium Focus](04-premium-focus.md) | One primary focus | Calm wall display | Less simultaneous overview |
| [5. Action Board](05-action-board.md) | State and next action | AI notices and household work | Can feel like workplace software |

## Initial recommendation

Prototype concepts 2 and 5 first. Use concept 5 for the notification/task model and concept 2 as a family morning layout. Validate both with adults and children before standardizing the first component library.
