## Usage, OAuth and limits

Regression tests first reproduced missing-price accounting and rotated-token
recovery failures through actual PostgreSQL/service paths. Pricing now requires a
compatible immutable snapshot, unit, actual model, context, tier and finite
nonnegative required rates. Valid zero is accepted; absent/invalid pricing remains
unknown. Known subtotals do not silently price the unknown remainder.
Owner/household/route/category/period-scoped NULL-dispatch attempts remain unresolved;
known preflight non-dispatch is excluded from possible billing. Legacy metadata is
used only where defensible. Forecasts are withheld with an unresolved-dispatch
explanation. Equivalent API USD is an explicit scenario, never an invoice.

A rotated encrypted credential is retained as pending validation when discovery
or JWKS is temporarily unavailable. Retry validates the latest candidate before
inference instead of reusing an older refresh token. Terminal identity/scope
failures clear the connection; serialized generation/revocation and owner checks
remain. The companion persists atomic mode-0600 token-free registration metadata
before exchange. Restart uses a fresh state, nonce and PKCE with the issued client
and VM identity, even without an old token export.

These follow the current official [sign-in flow](https://developers.openai.com/siwc/token-sharing-open-source/sign-in),
[recovery guidance](https://developers.openai.com/siwc/token-sharing-open-source/errors-and-recovery)
and [self-hosted VM guide](https://developers.openai.com/siwc/token-sharing-open-source/self-hosted-vms).
Host ID is attribution, not an authentication credential; transferring browser
credentials does not overwrite the VM host ID. Identity validation and Samvev
owner/household binding provide the authorization boundary.

**Actual account consent, eligibility/model access, live inference, balance,
expiry and real credit charging remain unverified. No live or paid provider call
was made.** All model transport tests are injected. Rich usage comprises seven
explicit synthetic SQL records: four known-priced, one confirmed unknown-price,
one unresolved dispatch and one known non-dispatch. The known subtotals are
1.41000000 credits and 0.05640000 equivalent API USD; they are fixture results,
not real account charges. Monthly forecast and account balance remain unknown.
Only the clearly labeled recovery screenshot injects a synthetic connected/pending
DTO; it does not prove live access.

To connect, follow [the complete guide](../../CHATGPT_PLAN_CONNECTION.md): on the
browser machine download both companion files and run Node 24 with the VM host ID
shown by Samvev; complete local browser consent. Securely SCP the private export
to this server, then run the shown owner/household-bound container import command.
After confirmed import delete transfer exports on **both machines**, retaining
only private token-free registration metadata. Refresh AI settings and explicitly
select/save an authorized model. Do not paste tokens into chat, Git or a LAN form.
