# ADR: Start with Google Keep share/import rather than promised sync

- **Status:** Proposed
- **Date:** 2026-09-06

## Context

Google Keep is useful to users, but a reliable supported full two-way synchronization path must be verified before it becomes a product promise.

## Decision

Implement iOS share-sheet import first and label it as a copy. Research official account/API capabilities in a separate integration issue.

## Consequences

Users gain a useful path early without making the core dependent on an unofficial integration.
