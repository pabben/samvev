# ADR: Adopt a reciprocal open-source license model

- **Status:** Accepted as initial policy
- **Date:** 2026-09-06

## Context

The goal is that everyone can use and contribute for free and benefit from one another's improvements, while optional paid hosting may fund operations.

## Decision

Use AGPL-3.0-or-later for server, worker, web and display code; plan MPL-2.0 for native iOS/WidgetKit code; use CC BY-SA 4.0 for original documentation and documentation artwork. Use DCO sign-off for contributions.

## Consequences

Network-hosted modifications to the AGPL components must be offered to users under the license. Paid hosting remains permitted. Mobile licensing must be reviewed before App Store distribution.
