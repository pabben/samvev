# ADR: Use Samvev as the working project name

- **Status:** Accepted, pending formal clearance
- **Date:** 2026-09-06

## Context

The earlier working name FamilyOS is already used and is generic. The project needs a distinct name that is not tied only to families, calendars or one AI provider.

## Decision

Use **Samvev** as repository and product working name. Use the taglines “Hverdagen, vevd sammen.” and “Everyday life, woven together.” where appropriate.

## Consequences

Repository naming becomes `pabben/samvev`. Existing concept images with earlier names are not published as final brand assets. Formal domain and trademark clearance is still required.
