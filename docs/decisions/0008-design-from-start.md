# ADR: Treat design as a foundation concern

- **Status:** Accepted
- **Date:** 2026-09-06

## Context

The product must remain understandable on mobile, large shared screens and compact wall displays instead of becoming a wall of text.

## Decision

Document and test five structurally different concepts, each in light and dark appearance. Build shared semantic tokens while allowing surface-specific layouts.

## Consequences

The first implementation prototypes Timeline/Person Columns and Action Board before selecting default components.
